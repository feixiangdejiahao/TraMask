# 动作、观察与小期望变换

把源测试写成 `T=(S,q,e)`：`S` 是构造输入、调用和状态修改组成的动作，`q` 是终点观察，`e` 是源断言提供的期望。测试要求 `q(run(S))=e`；等号也可代表源断言已有的结构比较谓词。

程序从其他测试提取动作上下文 `C`，在静态依赖约束允许的位置得到 `S'=C[S]`。观察可保留为 `q`，也可将已有观察的对象根作为一组端口，一致绑定到组合后的对象上，得到 `q'`。模型只补小表达式 `τ`：

```text
e' = τ(源期望集合 pre, 静态输入 arg)
候选测试：q'(run(C[S])) = e'

1. 提取：从源测试恢复 S、q、e，以及局部绑定、构造来源和依赖切片。
2. 枚举：程序闭合并拼接 C；按类型、构造来源和局部依赖一致绑定 q' 的端口；确定性排序、限额。
3. 补全：模型仅给 τ；程序在冻结的 pre/arg 上求 e'，固定断言后交独立评价。
```

`τ` 可以索引、切片和构造容器，做有限的算术、比较和纯内建调用；不能调用被测实现或读取候选实际输出。可选前提同样只在冻结输入上求值，不能变成运行时跳过失败的条件。动作、输入、观察和完整测试体始终由程序决定。这些限制约束模型能修改什么，不保证 oracle 正确；合法的常量、`pre[0]` 或其他纯表达式仍可能给出错误期望。

## 为什么必须允许换观察

固定 `q` 将程序状态分成等价类：若 `q(x)=q(y)`，任何只调整期望的 `τ` 都不能让同一输入下的这条观察区分 `x` 与 `y`。更灵活的期望并不能补回观察已经丢失的信息。

独立 toy 约定 `Sequence.put(v)` 把元素追加到末尾。源测试分别做一次 `put('a')`、`put('b')` 并检查数量为 1；另一测试用 `snapshot()` 检查空序列为 `[]`。程序组合出 `put('a'); put('b')`。保留数量观察时，正确追加和错误前插都会返回 2。

迁移已有 `snapshot()` 的接收者根后，程序得到 `q'=s.snapshot()`，静态动作参数为 `['a','b']`。模型给 `τ=list(arg)`，期望为 `['a','b']`；错误前插产生 `['b','a']`，因此被区分。观察与动作均来自程序拼接，模型只补期望关系。这里的顺序关系依赖 toy 的追加契约；仅凭三个源测试并不能证明它。

## 职责与证据边界

程序负责依赖目标、拼接位置、词法闭包和受限搜索，按父测试、上下文族与观察轮换预算；排序没有从逐例检出标签学习权重。模型负责静态分析无法决定的有限语义关系。候选代码可以提供依赖证据，其当前行为不能成为录制期望的依据。

语言语法适配、有限参数行展开和上下文提取是这一抽象的前端，决定能搜索哪些 `S/C/q`，不分别构成新的核心算法。历史 `A : B :: C : D` 基线依靠源码类比方格提出组合；当前方法不要求三个类比角齐全，另外搜索观察并补全期望关系。

源期望、类型与构造来源都不证明组合满足契约。当前仅在期望为完整静态值、测试前缀相同（含 decorator、签名和 setup，仅忽略测试名及输入/期望孔）时，附加前后源例子检查 `τ`；构造器内部常量孔不充当完整期望见证。这是关系一致性约束，可反证 `τ`，通过仍不是语义证明。换成不同观察时删除旧见证。有效报警仍须独立确认 oracle 和缺陷。

观察迁移仍限于同文件、同外围作用域：最多 3 个源端口，从 12 个可见目标端口中搜索，每模板至多 24 个绑定。同一根的重复引用与可证明的直接别名一致代换，保留局部依赖约束；不同构造调用不证明对象不别名。Python 直接 assert 的完整比较/布尔条件可作为观察，以断言成立所要求的 True 为源期望；Go/TS 沿用源中已有的布尔观察。

这些预算和语言支持是前端边界。未知别名、复杂控制和不可恢复的期望仍可能不受支持；局部 may 分析不证明观察无副作用，也未实现任意新观察或通用符号执行。独立 toy 验证了这一片段可实现，七批均已结束，均未获得已确认目标检出；多端口观察与源见证已在第五批评价，未带来有效检出，且没有实际适用的源见证。

## 当前实验与入口

七批均未确认七例中的目标缺陷，独立 toy 成功不等于 pilot 成功。当前完整回归为 1055 passed、21 subtests passed；各批冻结版本与失败分别记录。第七批两轮已确认目标命中均为 0/7，保留 3 次补全协议失败；r1 的两项报警经[执行后独立复核](../results/semantic_transport/batch7/postexecution_p1_second_review_v1.json)，其断言适用性仍未知，不能算作已确认缺陷或宣称没有误报。事前封存的 valid 标签保留，复核分歧另行记录。人工 oracle 审阅属于实验评价，不是算法已实现的自动正确性保证。
