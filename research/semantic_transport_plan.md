# 观察变换器：本轮方法与实验约定

2026-09-24；截止 08:25:54 UTC。本轮目标不变：七个任务两轮都检出目标且没有错误报警；五小时未达到则保留最好的已完成实现并报告缺口。七例是已经反复查看的开发集，不声称盲测或泛化已获证明。

## 核心假设

给定一个测试中的值或对象状态 x、观察切片 O，以及从另一个测试提取的上下文 C，组合需要满足一个小的观察变换关系：

```text
O'(C(x)) = τ(O(x), arg)    under g
```

程序负责选出 C、拼接位置和可用 O'，LLM 只补期望值变换 τ、可选前提 g 和观察编号。期望首先来自既有断言，不通过执行候选实现录制答案。关系是需要验证的语义假设，不把模型输出、类型兼容或源测试通过称为证明。

与前轮不同，上下文可以直接来自 donor 中的构造表达式或操作序列，不强制已有 A/B/C 三角齐全；oracle 也可以经过变换，不强制原样保持。是否由此提高真实检出率需要新实验。

## 程序与模型的分工

程序提取断言依赖、词法绑定、调用/构造来源及局部 may-state 边；识别测试内值端口与状态端口，从 donor 提取依赖闭合的上下文。连接优先依据已知类型、同一构造来源或同一调用实参位置，不按变量名含义或任务/API名分派规则。复杂控制和未知别名是分析限制，不宣称完整的 SDG 或类型证明。

程序确定性枚举和排序组合，保留源字节及依赖依据，再向模型展示少量待补全的关系。模型不能重写整个测试，也不能指定搜索哪些手工目标。输出只含候选 ID、观察 ID 和可解释的纯表达式；没有由自然语言标签构成的特征 schema。

τ/g 的表达式域限于源期望槽 pre、测试输入槽 arg、常量和容器、语言级算术/比较/布尔/索引及有限纯内建。禁止导入、任意函数调用和访问候选实际输出。程序对表达式求值、检查可用见证及前提，并发射目标语言断言。前提不能通过在运行时静默跳过失败输入来满足。表达式不成立或无法求值时保留明确拒绝原因。

最后检查组合确实进入观察的依赖锥、引入名字已绑定、构造的完整测试可解析；这些机械检查用于排除具体错误，不替代 oracle 语义审核。已有单元测试还要覆盖别名、重复调用、容器/字符串、条件和源期望不可得等独立例子。

## 实施和冻结

当前先修正已通过独立 toy 复现的局部依赖遗漏：未知类型实参的 may-effect、对象下标写、Go 声明初始化和循环变量的容器来源。旧快照与旧结果不改写；新检索/候选受影响时在新批次中记录。

开发者分工：核心算法与 oracle 表达式模块的代理不读取 pilot、参考或评审标签；根代理已了解旧轮失败，不能声称整个方法开发盲态。评价代理独立处理 oracle 和执行，不向生成实现提供逐例答案。任何后续源代码、模型提示、预算和输入变化均另开批次，禁止覆盖旧产物。

原有模型授权继续有效；目的地为 `.env` 指定 provider，模型为 `deepseek-v4-flash`。允许发送 issue、候选代码、已有测试及静态证据；参考补丁、隐藏 verifier、封存目标标签、评审结果与执行结果不进入模型。模型最终输出、失败、用量和算法/输入快照保留，缓存重放与新的模型采样区分。

首批预算在首次模型请求之前固定：程序最多保留 128 个候选，按父测试、上下文类型和观察轮换后展示前 24 个；模型一次最多补全 8 项，最终上限 10 项。每例 r1/r2 各一次独立请求，输入完全相同，temperature=0，禁用额外 thinking，输出预算各 10,000 tokens。状态上下文最多尝试 2,000 次拼接，最多保留 128 项；值上下文同样最多保留 128 项，两者汇总后再统一排序。没有可展示候选时零请求，失败不在原轮内重试。

首批实现每个候选只有一个原有观察，尚未实现新观察投影或自动加强断言；已提供见证核验接口，但本批生成器尚未附加语义见证，因此不能声称经见证验证。上下文包括源值替换、构造包装和同一构造来源对象的局部操作序列。未知别名、复杂控制和静态期望不可得可能被拒绝。期望可以是完整常量或原期望表达式中的唯一常量孔；后一种保留原外层表达式，模型明确获知只替换该孔。支持范围及拒绝数量需要随真实实验报告。

本轮优先完成七例两轮。现有独立控制可用于反证与边界检验，但不能称为未见数据。评价方法沿用[本轮独立评价计划](semantic_composition_evaluation_plan.md)，不能把单元测试、生成数量或零报警替代目标检出。

## 论文依据与可检验的差别

MR-Coupler（FSE 2026）启发“先计算关系搜索范围，再生成并验证关系”；本轮关系由测试上下文作用于观察来定义，不预设每次都是结果保持。[论文](https://arxiv.org/html/2604.10126v1)

ISSTA 2026 的 *Evaluating and Mitigating the Misguidance Effect of Buggy Code in LLM-Generated Unit Tests* 研究候选代码对 oracle 生成的误导，并探索基于规格的提示。本轮据此将程序实现的依赖证据与期望语义来源区分，优先使用 issue、公开契约和原有断言；这不能保证模型推断正确。[作者论文](https://arxiv.org/html/2607.22883v1)

ChaCo（ICSE 2026）明确将补丁覆盖与发现当前补丁缺陷区分，并假定生成回归测试时 PR 正确。本轮不采用其“修改测试直到在当前实现上通过”的目标；候选失败是待审核发现信号，不能成为迎合实现修改 expected 的理由。[作者论文](https://software-lab.org/publications/icse2026_ChaCo.pdf)

独立 toy 支持部分组合与观察的可实现性，前两批尚无 pilot 有效检出。核心待检验问题是：受依赖约束的上下文组合，配合小的观察变换器，能否同时提高组合检出和 oracle 有效性，而不扩大为模型自由编写测试。

## 第三批之前的扩展声明

前两批的失败与用量完整保留在[结果记录](semantic_transport_results.md)。第三批继续采用同一个组合单位 `动作切片 S + 观察切片 q + 期望变换 τ`：程序选择并拼接 S/q，模型仅填 τ。新增前端扩大候选覆盖，不根据 case 名称或特定 API 分派算法。

- 有限参数行部分求值：从源码参数表恢复完整行，在原词法绑定下展开纯 f-string/字符串运算。未知调用和参数重绑不假装已求值；最多新增 8,192 个静态 donor。
- 操作区域：在 Python 上下文管理器体和局部声明周围提取独立直线区域；原声明、控制块和源码位置保留，插入后检查到目标观察的 may-state 路径。保存了返回值的调用可保留完整 RHS 求值而丢弃未使用赋值，避免漏掉有副作用的操作；包装和求值顺序保留，未知调用不当作已闭合依赖。
- 局部字符串上下文：从同一调用位置的源码值对学习差异，以唯一局部 token 锚点迁移，并保留目标字符串的其余部分；最多 8,000 次迁移尝试。未知 receiver 的构造来源仅是近似约束，不声称类型已证明。
- 参数位置交换：不同构造表达式可占据同一已解析调用参数位置，程序搬运词法闭合的源表达式；最多 4,000 次尝试。位置兼容仍不证明泛型实参、输入契约和 oracle 正确。
- 观察迁移：按同作用域、类型/构造来源匹配源观察根，把闭合观察切片放到组合后的对象上。最多 256 个观察模板、每动作 4 个投影、4,096 次匹配、128 个投影候选。保留源期望槽编号，模型不能修改实际值表达式或观察源码。

各上下文前端最多保留 128 项，合并后按父测试/上下文族/观察轮换，基底动作最多 128 项；加上最多 128 个观察投影后再次轮换至最终 128 项。展示 24 项、模型最多补全 8 项、r1/r2 各一次请求和 10,000 输出 tokens 均不变。第三批显式开启 `thinking=enabled, reasoning_effort=medium`，修正提示只机械复制原 expected 的倾向；因此不能宣称与前批是同候选空间或单因素对照。

集合字面量、字典顺序编码、冻结重放及参数期望重绑检查已依据独立反例修正。新功能先跑独立 toy 和全套回归，再冻结新的算法/提示快照。任何新增有效报警仍需事前封存 oracle 标签与独立目标确认；源码分析通过和语法/类型兼容不替代语义证据。
