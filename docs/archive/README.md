## 历史汇报的构建

20261001_test_augmentation_slides.pdf 与同名 .tex 配套保存。从仓库根目录执行 `make -C docs` 可重新构建。构建需要 latexmk、pdflatex、Beamer、TikZ/PGF、FontAwesome5、Latin Modern、AMS math、booktabs 和 listings。中间文件写入 docs/build/。本次整理保留了原 PDF，未重新编译。
