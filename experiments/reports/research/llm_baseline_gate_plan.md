# 模型生成候选的后置语义筛选

2026-09-23，全部 baseline 生成请求已结束，在新增筛选请求之前固定。设计时根代理已看到独立人工 oracle 分类汇总，尚未查看本轮候选/参考运行结果。因此这是探索性补充，不能称预先设计的盲态消融。

对 `llm_generation_baseline/batch1` 的 P1–P7、r1/r2 分别使用同一个自动语义 gate。每轮至多一次请求，只选择该轮已经冻结的候选 ID，不修改代码或 expected，也不接收人工审计、候选执行或参考结果。四个机械检查不支持的原提案保持无效生成，不进入筛选。输入继续使用该轮冻结的 issue、来源测试、生产上下文和固定代码编辑。

沿用 `generic_composition/gate.py` 的原语义判断规则，仅将开头的构造来源说明改成模型提案经过语法/绑定检查，避免冒称来自程序类比。模型仍为 `deepseek-v4-flash`，每次最多 10,000 输出 tokens。保存新请求、完整响应、原候选来源与代码哈希；历史直接生成结果保留。

筛选后的测试和源控制重新物化并执行，因为测试集合改变可能影响执行。独立 oracle 审计可在候选完整字节一致时复用，但仍分别报告 r1/r2 的有效检出、错误/未知报警、无输出和全部生成＋筛选成本。新增阶段不构成测试类比算法的改进，不与原方法合并报成绩。
