# 报告阅读入口

本目录保存链接已更新的报告副本。原报告保持不变。正文中的历史路径可用 [路径查询工具](../../scripts/result_paths.py) 转换。

按实验查找请打开 [主要 pilot](../pilots/README.md)，按报告查找请打开 [报告目录](../../docs/README.md)。

`source_manifest.json` 保存原文路径、阅读副本路径和两者的校验值。未能定位的历史链接也记录在该文件中。

运行 `python3 scripts/build_experiment_index.py` 会更新本目录。请修改原报告或生成脚本，不要直接编辑阅读副本。
