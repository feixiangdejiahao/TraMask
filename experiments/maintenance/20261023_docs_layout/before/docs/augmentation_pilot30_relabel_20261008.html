正标签现在表示什么

原标签回答“验证漏了什么”。新主标签回答“哪项遗漏可以暴露与原任务失败有关的补丁错误”。它需要同时满足以下条件。

  1. 原验证没有有效检查这组相关条件及其共同结果。
  2. 公开要求支持输入和预期。该检查能暴露原补丁错误。
  3. 该错误对应原 benchmark 的失败行为，或与其使用同一错误规则。

第三项用于对齐本次的修复率目标。它比单纯发现原补丁的其他边界错误更严格。源码支持错误，但尚未建立验收联系的目标，仍列为待定。这不表示目标无用。

Agent 未运行已有联合测试的情况应归为选测问题。本次保留的七项沿用原逐项记录中的遗漏检查，没有把已知未运行测试改写成新生成需求。

源码语义判断可以支持正标签，但必须说明触发条件和错误路径。T12 使用这一证据。它没有运行新的碰撞输入。其余六项保留目标都有原验收失败记录。T24 还具有已完成的原补丁与 gold 差分测试。

Gold 是 benchmark 提供的参考补丁。Gold 通过不能单独证明预期正确。Gold 编译失败或缺少私有接口，也不能单独证明原补丁错误。公开要求、原行为和失败关联必须共同支持判断。
