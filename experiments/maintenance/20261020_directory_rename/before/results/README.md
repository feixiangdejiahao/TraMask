# 历史结果存放位置

本目录保存早期实验的原始输出和共用运行材料。按实验读取时，先打开 [主要 pilot 索引](../experiments/pilots/README.md) 或 [全部结果目录](../experiments/INVENTORY.md)。

`experiments/<主题>/results/` 中的部分目录是指向这里的链接。它们不是另一份实验结果。不要重复计数。

旧协议和来源凭据可能包含真实绝对路径。因此，本次整理保留文件名、目录名和物理位置。新的统一名称位于 `experiments/pilots/`，各入口通过符号链接访问原数据。

新运行放在 `experiments/<主题>/results/YYYYMMDD_<主题>_n<案例数>_r<运行版本>/`。目录和文件约定见 [实验管理说明](../experiments/README.md)。既有脚本仍可使用原路径。
